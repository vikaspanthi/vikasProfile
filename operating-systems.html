OS 01OS Structure & System Calls

An operating system manages hardware resources and offers abstractions such as processes and files. A system call crosses from user mode into the kernel to request a protected service.

Application → system call → kernel → device / resource

OS 02Processes, Threads & IPC

A process owns an address space and resources; threads in one process share much of that state. Pipes, message queues, and shared memory support interprocess communication.

Ready → Running → Waiting → Ready
             ↘ Terminated

Quick check: Which communication method needs explicit synchronization of shared data?

OS 03CPU Scheduling

FCFS runs in arrival order; SJF prefers shorter bursts; Round Robin allocates a time quantum. Average waiting time equals the average time spent in the ready queue.

P1: burst 5, P2: burst 2 (both arrive at 0)
FCFS P1→P2: waits 0, 5; average 2.5
SJF  P2→P1: waits 0, 2; average 1

Quick check: How can a very small Round Robin quantum affect overhead?

OS 04Synchronization & Deadlock

Critical sections protect shared state. Mutexes and semaphores coordinate access. Deadlock requires mutual exclusion, hold and wait, no preemption, and circular wait together.

lock.acquire()
try: update_shared_state()
finally: lock.release()

Quick check: How can a global lock order prevent circular wait?

OS 05Memory Management & Virtual Memory

Paging maps virtual pages to physical frames. A page fault occurs when a referenced page is not currently resident. Replacement policies include FIFO and LRU.

Virtual address = page number + offset
Page table: page number → frame number

Quick check: What is the difference between internal fragmentation and a page fault?
