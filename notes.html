Python Programming

01Python Basics & Syntax

Python uses indentation to group statements. Names are case sensitive. Comments begin with #.

name = "Vikas"
if name:
    print(f"Hello, {name}!")

Quick check: What happens if the indented print line is aligned with if?

02Variables & Data Types

Variables refer to objects. Common built-in types include int, float, bool, str, and NoneType.

count = 3
price = 2.5
print(type(count), count + price)  # int, 5.5

Quick check: Why is "3" + 2 an error?

03Operators & Control Statements

== compares values; is checks identity. Use if, elif, and else for branches.

score = 76
if score >= 75:
    result = "pass"
else:
    result = "review"

Quick check: How does and short circuit?

04Loops & Functions

for iterates over an iterable; while repeats while a condition is true. Functions return None unless they explicitly return a value.

def squares(limit):
    return [n * n for n in range(limit)]
print(squares(4))  # [0, 1, 4, 9]

Quick check: Why does range(4) stop at 3?

05Strings, Lists, Tuples, Sets & Dictionaries

Strings and tuples are immutable. Lists keep order and can change. Sets store unique elements. Dictionaries map unique keys to values.

items = ["a", "b", "a"]
print(set(items))       # {'a', 'b'} in any order
print({"a": 2}["a"])  # 2

Quick check: Which collection is best for fast membership checks?

06Lambda & Scope

A lambda is a small expression function. Name lookup normally follows local, enclosing, global, then built-in scope.

pairs = [("A", 3), ("B", 1)]
print(sorted(pairs, key=lambda pair: pair[1]))

Quick check: When would you use nonlocal?

07Object-Oriented Programming

Classes group state and behavior. An instance method receives the instance as its first argument, conventionally called self.

class Counter:
    def __init__(self):
        self.value = 0
    def increment(self):
        self.value += 1

Quick check: What is the difference between a class attribute and an instance attribute?

08Exceptions & File Handling

Catch specific exceptions. A with block closes a file even when an error occurs.

try:
    with open("notes.txt", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    content = ""

Quick check: Why is catching every exception with bare except: risky?

09Modules & Packages

Modules are Python files that can be imported. Packages organize related modules. Imports execute module-level code on first import in a process.

from math import sqrt
print(sqrt(25))  # 5.0

Quick check: What does if __name__ == "__main__": control?

10Iterators & Generators

An iterator provides items one at a time via next(). A generator uses yield and resumes where it left off.

def numbers():
    yield 1
    yield 2
print(list(numbers()))  # [1, 2]

Quick check: Why can a generator save memory?

11Decorators & Advanced Concepts

A decorator receives a function and returns a callable, often adding behavior around the original function.

def announce(fn):
    def wrapper(*args, **kwargs):
        print("Calling function")
        return fn(*args, **kwargs)
    return wrapper

Quick check: Why should a wrapper forward *args and **kwargs?

Operating Systems

OS 01OS Structure & System Calls

An operating system manages hardware resources and offers abstractions such as processes and files. A system call crosses from user mode into the kernel to request a protected service.

Application → system call → kernel → device / resource

Quick check: Why should ordinary programs run outside kernel mode?

OS 02Processes, Threads & IPC

A process owns an address space and resources; threads in one process share much of that state. Pipes, message queues, and shared memory support interprocess communication.

Ready → Running → Waiting → Ready
             ↘ Terminated

Quick check: Which communication method needs explicit synchronization of shared data?

OS 03CPU Scheduling

FCFS runs in arrival order; SJF prefers shorter bursts; Round Robin allocates a time quantum. Average waiting time equals the average time spent in the ready queue.

P1: burst 5, P2: burst 2 (both arrive at 0)
FCFS P1→P2: waits 0, 5; average 2.5
SJF  P2→P1: waits 0, 2; average 1

Quick check: How can a very small Round Robin quantum affect overhead?

OS 04Synchronization & Deadlock

Critical sections protect shared state. Mutexes and semaphores coordinate access. Deadlock requires mutual exclusion, hold and wait, no preemption, and circular wait together.

lock.acquire()
try: update_shared_state()
finally: lock.release()

Quick check: How can a global lock order prevent circular wait?

OS 05Memory Management & Virtual Memory

Paging maps virtual pages to physical frames. A page fault occurs when a referenced page is not currently resident. Replacement policies include FIFO and LRU.

Virtual address = page number + offset
Page table: page number → frame number

Quick check: What is the difference between internal fragmentation and a page fault?

Software Engineering

SE 01Requirements Engineering

Functional requirements describe behavior. Nonfunctional requirements state constraints or quality targets such as latency, reliability, and accessibility. Make them measurable.

Vague: "The app is fast."
Testable: "95% of searches finish within 2 seconds."

Quick check: Is an audit log a functional requirement or a quality constraint?

SE 02Development Models

Waterfall separates phases; iterative development revisits a product in increments; agile practices emphasize frequent feedback. Choose based on uncertainty, risk, and release needs.

Plan → Build → Evaluate → Adapt → next iteration

Quick check: Why is early feedback useful when requirements are uncertain?

SE 03UML & Software Design

Use case diagrams show actors and goals, class diagrams show structure, and sequence diagrams show messages over time. Design for clear responsibilities and low coupling.

Client → OrderService: placeOrder()
OrderService → Inventory: reserve()

Quick check: Which diagram best shows a time-ordered interaction?

SE 04Testing & Coverage

Unit tests check components; integration tests check interfaces; system tests exercise the whole product. Statement coverage measures executed statements and does not prove correctness.

Coverage = executed statements / total statements × 100%

Quick check: Can 100% statement coverage miss an incorrect boundary condition?

SE 05Maintenance & Configuration

Maintenance includes corrective, adaptive, perfective, and preventive work. Version control records changes; code review and automated tests reduce regression risk.

Issue → change → review → test → release

Quick check: Is updating software for a new operating system adaptive or corrective maintenance?
