01Python Basics & Syntax

Python uses indentation to group statements. Names are case sensitive. Comments begin with #.

name = "Vikas"
if name:
    print(f"Hello, {name}!")

Quick check: What happens if the indented print line is aligned with if?

02Variables & Data Types

Variables refer to objects. Common built-in types include int, float, bool, str, and NoneType.

count = 3
price = 2.5
print(type(count), count + price)  # int, 5.5

Quick check: Why is "3" + 2 an error?

03Operators & Control Statements

== compares values; is checks identity. Use if, elif, and else for branches.

score = 76
if score >= 75:
    result = "pass"
else:
    result = "review"

Quick check: How does and short circuit?

04Loops & Functions

for iterates over an iterable; while repeats while a condition is true. Functions return None unless they explicitly return a value.

def squares(limit):
    return [n * n for n in range(limit)]
print(squares(4))  # [0, 1, 4, 9]

Quick check: Why does range(4) stop at 3?

05Strings, Lists, Tuples, Sets & Dictionaries

Strings and tuples are immutable. Lists keep order and can change. Sets store unique elements. Dictionaries map unique keys to values.

items = ["a", "b", "a"]
print(set(items))       # {'a', 'b'} in any order
print({"a": 2}["a"])  # 2

Quick check: Which collection is best for fast membership checks?

06Lambda & Scope

A lambda is a small expression function. Name lookup normally follows local, enclosing, global, then built-in scope.

pairs = [("A", 3), ("B", 1)]
print(sorted(pairs, key=lambda pair: pair[1]))

Quick check: When would you use nonlocal?

07Object-Oriented Programming

Classes group state and behavior. An instance method receives the instance as its first argument, conventionally called self.

class Counter:
    def __init__(self):
        self.value = 0
    def increment(self):
        self.value += 1

Quick check: What is the difference between a class attribute and an instance attribute?

08Exceptions & File Handling

Catch specific exceptions. A with block closes a file even when an error occurs.

try:
    with open("notes.txt", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    content = ""

Quick check: Why is catching every exception with bare except: risky?

09Modules & Packages

Modules are Python files that can be imported. Packages organize related modules. Imports execute module-level code on first import in a process.

from math import sqrt
print(sqrt(25))  # 5.0

Quick check: What does if __name__ == "__main__": control?

10Iterators & Generators

An iterator provides items one at a time via next(). A generator uses yield and resumes where it left off.

def numbers():
    yield 1
    yield 2
print(list(numbers()))  # [1, 2]

Quick check: Why can a generator save memory?

11Decorators & Advanced Concepts

A decorator receives a function and returns a callable, often adding behavior around the original function.

def announce(fn):
    def wrapper(*args, **kwargs):
        print("Calling function")
        return fn(*args, **kwargs)
    return wrapper

Quick check: Why should a wrapper forward *args and **kwargs?
